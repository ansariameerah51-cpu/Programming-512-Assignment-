SMART CAMPUS RESOURCE BOOKING SYSTEM - PROGRAMMING 512

REQUIREMENTS
- Python 3 installed on Windows
- Tkinter and SQLite are included with most standard Python installations

HOW TO RUN
1. Extract the ZIP file into a folder.
2. Open Command Prompt in that folder.
3. Run: python smart_campus.py
4. The database file smart_campus.db will be created automatically in that folder.

DEMO ACCOUNTS
Campus Administrator: username admin, password Admin123!
System Operator: username operator, password Operator123!
Lecturers can create their own accounts using Register as Lecturer.

FEATURES
- Tkinter graphical interface
- Lecturer registration and login
- Role-based lecturer, campus administrator and system operator access
- SQLite persistence for users, campuses, resources and bookings
- Three campuses with different booking duration and time policies
- Add, update and remove resources (resources with booking history cannot be removed)
- Booking creation, overlap checks, future booking cancellation and history
- Campus usage reports and cross-campus comparison for system operators
- OOP user classes and structured campus policy data

NOTES
- Demo credentials are for testing only. Change/remove them before real deployment.
- This is a student project prototype, not a production-ready security system.
